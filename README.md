# 边坡雷达监测系统

## 🚀 快速启动

双击运行 `启动雷达系统.bat` 即可启动系统。

## 📡 系统地址

- **前端系统**: http://localhost:6098
- **API服务**: http://localhost:8099
- **Swagger文档**: http://localhost:8099/swagger

## 🛠️ 技术栈

- **后端**: ASP.NET Core 8.0 + SQLite + TDengine
- **前端**: Vue 3 + Vite + Cesium
- **通信**: Netty + MQTT
- **数据库**: SQLite + TDengine

## 📋 系统功能

- 雷达数据采集与处理
- 实时告警监控
- 图像分析与生成
- 设备状态管理
- 数据可视化展示

## 🔧 开发环境

- .NET 8.0 SDK
- Node.js 18+
- Visual Studio 2022 或 VS Code
