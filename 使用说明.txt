===============================================
   边坡雷达监测系统 - 启动说明
===============================================

📦 项目文件
--------------
  启动系统.bat      - 一键编译、部署、启动脚本
  start.ps1         - PowerShell 启动脚本（备用）

🚀 快速启动
--------------
  双击运行: 启动系统.bat

  或在命令行中运行:
  > 启动系统.bat

📋 脚本功能
--------------
  [1/6] 检查 .NET 环境
        - 验证 .NET 8.0 SDK 是否安装
        - 显示当前版本信息

  [2/6] 检查 Node.js 环境
        - 验证 Node.js 是否安装（可选）
        - 如未安装则跳过前端构建

  [3/6] 构建前端项目
        - 自动检测可用的前端项目:
          · RadarSystem.WebAPI\ClientApp
          · RadarSystem.WebAPI\ClientApp_OLD
          · RadarContrl\dist (预构建)
        - 执行 npm install
        - 执行 npm run build
        - 如已有构建产物，询问是否重新构建

  [4/6] 还原后端依赖
        - 执行 dotnet restore

  [5/6] 编译后端项目
        - 执行 dotnet build (Release)

  [6/6] 启动系统服务
        - 自动打开浏览器访问前端
        - 启动后端 API 服务

🌐 访问地址
--------------
  前端界面: http://localhost:6098
  API 服务: http://localhost:8099
  API 文档: http://localhost:8099/swagger

👤 默认账户
--------------
  用户名: admin
  密码:   admin123

⚙️ 环境要求
--------------
  必需:
    ✓ .NET 8.0 SDK
      下载: https://dotnet.microsoft.com/download

  可选（前端开发）:
    ○ Node.js 18+ 
      下载: https://nodejs.org

🔧 故障排除
--------------
  1. 如果提示 ".NET SDK 未安装"
     → 安装 .NET 8.0 SDK

  2. 如果前端构建失败
     → 检查 Node.js 是否安装
     → 删除 node_modules 后重试
     → 使用预构建的 RadarContrl\dist

  3. 如果后端编译失败
     → 检查代码错误
     → 运行: dotnet restore
     → 运行: dotnet build

  4. 如果端口被占用
     → 关闭占用端口的程序
     → 或修改 Program.cs 中的端口配置

  5. 如果数据库错误
     → 检查 Data/radar.db 文件权限
     → 删除数据库文件重新创建

📝 高级用法
--------------
  使用 PowerShell 脚本（更多选项）:
  
  # 标准启动
  > .\start.ps1

  # 跳过前端构建
  > .\start.ps1 -SkipBuild

  # 开发模式（热重载）
  > .\start.ps1 -DevMode

🛑 停止系统
--------------
  在命令行窗口中按: Ctrl + C

📞 技术支持
--------------
  如遇问题，请检查:
    - logs/ 目录下的日志文件
    - 命令行窗口的错误信息
