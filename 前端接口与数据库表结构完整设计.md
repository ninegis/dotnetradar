# 前端接口与数据库表结构完整设计

**设计日期**: 2025-10-25  
**设计原则**: 
1. 所有配置信息拆分为独立字段，不使用JSON存储
2. 所有表都包含ProjectId，支持多项目隔离
3. 参考Java原有接口，但优化为更合理的C#实现

---

## 📊 一、前端页面与接口映射

### 1. 项目配置 (ProjectConfig)

#### 1.1 项目信息配置

**前端页面**: `ProjectConfig.vue`, `ProjectEdit.vue`, `ProjectAdd.vue`

**前端调用接口**:
```javascript
// 获取项目列表
ApiRadar.getRadarData() 
→ GET /api/project/list

// 添加项目
ApiRadar.addProject(projectId, projectName, projectDescribe, contact, phone, email, lon, lat, alt)
→ POST /api/protocol/add/project

// 更新项目信息
ApiRadar.updateProjectInfo(projectId, name, description, contact, phone, email)
→ POST /api/custom/updateProjectInfo

// 删除项目
ApiRadar.DeleteProject(projectId)
→ POST /api/protocol/remove/project
```

**数据库表**: `Projects`

```sql
CREATE TABLE Projects (
    ProjectId TEXT PRIMARY KEY,           -- 项目ID
    ProjectName TEXT NOT NULL,            -- 项目名称
    Description TEXT,                     -- 项目描述
    ContactPerson TEXT,                   -- 联系人
    ContactPhone TEXT,                    -- 联系电话
    ContactEmail TEXT,                    -- 联系邮箱
    Longitude REAL DEFAULT 0,             -- 经度
    Latitude REAL DEFAULT 0,              -- 纬度
    Elevation REAL DEFAULT 0,             -- 高程
    StartTime TEXT,                       -- 开始时间
    EndTime TEXT,                         -- 结束时间
    CameraLongitude REAL,                 -- 相机经度
    CameraLatitude REAL,                  -- 相机纬度
    CameraAltitude REAL,                  -- 相机高程
    CameraHeading REAL,                   -- 相机航向角
    CameraPitch REAL,                     -- 相机俯仰角
    CameraRoll REAL,                      -- 相机翻滚角
    Status INTEGER DEFAULT 1,             -- 状态 (1:启用, 0:禁用)
    CreateTime TEXT NOT NULL,             -- 创建时间
    UpdateTime TEXT                       -- 更新时间

```

#### 3.1 雷达基础参数配置

**前端传递参数**:
```javascript
{
    projectId: "string",
    deviceId: "string",
    name: "string",              // 设备名称
    factoryId: "string",         // 出厂ID
    longitude: 0.0,              // 经度
    latitude: 0.0,               // 纬度
    height: 0.0,                 // 高程
    radarOri: 0.0,               // 零点朝向
    ImgAngleStart: 0.0,          // 图像起始角度

    RngMax: 1000.0,              // 最大距离
    FreqBand: "0",               // 频段
    AnteBeam_half: 60.0,         // 天线波束半角
    dataVersion: "0",            // 数据版本
    modelSelect: "0"             // 模型选择（MIMO Lite专用）
}
```

**数据库表**: `radar_params` (新建)

```sql
CREATE TABLE radar_params (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id TEXT NOT NULL,             -- 项目ID
    device_id TEXT NOT NULL,              -- 设备ID
    img_angle_start REAL DEFAULT 0,       -- 图像起始角度（度）
    img_angle_end REAL DEFAULT 360,       -- 图像结束角度（度）
    rng_min REAL DEFAULT 0,               -- 最小距离（米）
    rng_max REAL DEFAULT 1000,            -- 最大距离（米）
    freq_band TEXT DEFAULT '0',           -- 频段
    ante_beam_half REAL DEFAULT 60,       -- 天线波束半角（度）
    data_version TEXT DEFAULT '0',        -- 数据版本
    model_select TEXT,                    -- 模型选择（MIMO Lite专用）
    create_time TEXT NOT NULL,            -- 创建时间
    update_time TEXT,                     -- 更新时间
    FOREIGN KEY (project_id) REFERENCES Projects(ProjectId) ON DELETE RESTRICT,
    FOREIGN KEY (device_id) REFERENCES Devices(DeviceId) ON DELETE CASCADE,
    UNIQUE(project_id, device_id)         -- 每个设备一个配置
);
```

**说明**: 
- 设备的基础信息（名称、出厂ID、坐标、朝向）保存在`Devices`表
- 雷达的成像参数（角度、距离、频段等）保存在`radar_params`表

```
kotjavrradar/

├── canon-mqtt/             # MQTT通信

```

### Java接口映射到C#

| Java模块 | Java Controller | C# Controller | 说明 |
|---------|----------------|---------------|------|
| canon-server | ProjectController | ProjectController | 项目管理 |
| canon-device | DeviceController | DeviceController | 设备管理 |
| canon-alarm | AlarmController | ProtocolController (部分) | 告警管理 |
| canon-radar | RadarController | ProtocolController (部分) | 雷达参数 |
| canon-image-analysis | ImageController | ProtocolController (部分) | 图像配置 |
| canon-data-analysis | DataController | CustomController | 数据管理 |

**主要差异**:
1. Java使用多模块Maven项目，C#使用单体项目+多个类库
2. Java的接口分散在多个Controller，C#集中在`ProtocolController`
3. Java使用JSON存储配置，C#改为独立字段存储
