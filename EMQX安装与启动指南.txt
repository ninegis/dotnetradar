【需要安装EMQX】

方法1: 手动下载（推荐）
────────────────────────────────────────
1. 访问: https://www.emqx.io/downloads
2. 选择: EMQX Broker 开源版
3. 下载: Windows版本 (zip)
4. 解压到: C:\emqx
5. 启动: C:\emqx\bin\emqx.cmd start
6. 验证: netstat -ano | findstr ":1883 :8083"

方法2: 使用Scoop包管理器
────────────────────────────────────────
powershell -c "irm get.scoop.sh | iex"
scoop install emqx
emqx start

方法3: Docker（需先安装Docker Desktop）
────────────────────────────────────────
docker run -d --name emqx ^
  -p 1883:1883 ^
  -p 8083:8083 ^
  -p 18083:18083 ^
  emqx/emqx:latest

【启动EMQX后】

1. 检查端口
   netstat -ano | findstr ":1883 :8083 :18083"
   
   应看到:
   TCP  0.0.0.0:1883   LISTENING  (MQTT)
   TCP  0.0.0.0:8083   LISTENING  (WebSocket)
   TCP  0.0.0.0:18083  LISTENING  (Dashboard)

2. 访问Dashboard
   http://localhost:18083
   用户名: admin
   密码: public

3. 启动雷达系统
   cd RadarSystem.WebAPI
   dotnet run -c Release

4. 验证雷达系统端口
   netstat -ano | findstr ":1030 :6098 :8099"

【完整端口列表】
