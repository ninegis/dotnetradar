## 详细数据包解析示例

### 形变数据包 (0x0302) 十六进制格式

```
完整数据包结构 (示例):

5A5A 00000014 0302 00100000 [1048576字节数据] CHECKSUM
│    │        │    │         │                 │
│    │        │    │         │                 └─ 校验和
│    │        │    │         └─ 形变数据 (1MB)
│    │        │    └─ 数据长度 (0x00100000 = 1048576)
│    │        └─ 命令代码 (0x0302 = 形变数据上报)
│    └─ 从机ID (0x00000014 = 20)
└─ 命令头 (0x5A5A = 上行命令)

实际十六进制:
5A 5A 00 00 00 14 03 02 00 10 00 00 [数据...] FF FF
```

### 代码解析流程

```csharp
// 1. 接收原始字节数组
byte[] data = [0x5A, 0x5A, 0x00, 0x00, 0x00, 0x14, ...];

// 2. 转换为十六进制字符串
string hexString = "5A5A000000140302...";

// 3. 提取命令代码
string command = hexString.Substring(12, 4);  // "0302"

// 4. 提取从机ID
string slaveIdHex = hexString.Substring(4, 8);  // "00000014"
int slaveId = Convert.ToInt32(slaveIdHex, 16);  // 20
string slaveIdStr = slaveId.ToString();  // "20"

// 5. 查找设备ID
string deviceId = GetDeviceId("20");  // "20"

// 6. 根据命令类型处理
switch (command)
{
    case "0302":  // 形变数据
        HandleImageData("20", "20", "00", "形变", data);
        break;
}
```

## 故障处理

### 设备离线检测

```
监控服务 (每60秒检查)
  ├─ 查询心跳时间戳: _heartbeatTimeMap["20"]
  ├─ 计算时间差: NOW() - last_heartbeat
  └─ 判断: 
      ├─ < 120秒 → 在线 ✅
      └─ ≥ 120秒 → 离线 ❌ → 触发报警
```

### 数据丢失处理

```
如果文件保存失败:
  ├─ 重新入队 (最多3次)
  ├─ 记录错误日志
  └─ 发送报警通知
```

## 总结

**设备ID=20的圆弧雷达**数据流转关键路径：

1. **TCP连接** → 1030端口
2. **协议解析** → ArcRadarServerHandler
3. **命令识别** → 0x0302 (形变数据)
4. **SlaveId映射** → "20" → DeviceId "20"
5. **入队列** → ConcurrentQueue<ArcRadarImage>
6. **异步保存** → `../../data/project/PROJECT001/radar/20/00_YYYYMMDDHHmmss.dat`
7. **MQTT通知** → `/dev/heartbeat`, `/dev/radar/defo/device/info`

**特点**:
- ✅ 异步处理，不阻塞接收
- ✅ 队列缓冲，避免数据丢失
- ✅ 文件系统 + MQTT双重通知
- ✅ 完整的设备状态监控
