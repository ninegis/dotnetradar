===============================================
   边坡雷达监测系统 - 快速启动指南
===============================================

📦 一键启动
--------------
  双击运行: 启动系统.bat

  脚本会自动完成:
  [1/6] 检查 .NET 环境
  [2/6] 检查 Node.js 环境  
  [3/6] 前端构建
  [4/6] 还原后端依赖
  [5/6] 编译后端项目
  [6/6] 启动系统服务

🌐 访问地址
--------------
  启动成功后:
  🌐 前端界面: http://localhost:6098
  📡 API 服务: http://localhost:8099
  📖 API 文档: http://localhost:8099/swagger

👤 默认账户
--------------
  用户名: admin
  密码:   admin123

⚙️ 环境要求
--------------
  必需:
    ✓ .NET 8.0 SDK (或更高版本)
      下载: https://dotnet.microsoft.com/download

  可选 (用于前端开发):
    ○ Node.js 18+
      下载: https://nodejs.org
      
  说明: 如果有现成的前端构建文件
        (RadarSystem.WebAPI\wwwroot)
        可以不安装 Node.js

📂 项目结构
--------------
  当前前端项目:
  └─ RadarSystem.WebAPI\ClientApp\
     ├─ src\                    # 源代码
     ├─ package.json            # 依赖配置
     ├─ vite.config.ts          # Vite配置
     └─ (构建输出到 ../wwwroot)

  备用前端项目:
  └─ RadarContrl\

     ├─ vite.config.js          # Vite配置
     └─ (独立的前端项目)

🔧 故障排除
--------------

问题 1: 前端构建失败
  错误: "Could not load .../views/XXX.vue"
  
  解决方案:
  1) 检查所有 .vue 文件是否完整（不为空）
  2) 进入 ClientApp 目录检查:
     cd RadarSystem.WebAPI\ClientApp
     ls src/views/*.vue
  3) 删除 node_modules 目录
  4) 重新运行启动脚本

---

问题 2: npm install 失败
  错误: "npm ERR! ..."
  
  解决方案:
  1) 清理 npm 缓存:
     npm cache clean --force
  2) 删除 node_modules 和 package-lock.json:
     cd RadarSystem.WebAPI\ClientApp
     rd /s /q node_modules
     del package-lock.json
  3) 重新运行启动脚本

---

问题 3: 找不到 package.json
  错误: "找不到前端项目"
  
  解决方案:
  1) 检查文件是否存在:
     dir RadarSystem.WebAPI\ClientApp\package.json
  2) 确认目录结构正确
  3) 如果文件缺失，从备份恢复

---

问题 4: 端口被占用
  错误: "地址已在使用中"
  
  解决方案:
  1) 关闭占用端口的程序
  2) 查找占用端口的进程:
     netstat -ano | findstr "6098"
     netstat -ano | findstr "8099"
  3) 结束进程:
     taskkill /F /PID <进程ID>

---

问题 5: .NET SDK 未找到
  错误: "未找到 .NET SDK"
  
  解决方案:
  1) 安装 .NET 8.0 SDK 或更高版本
  2) 确认安装成功:
     dotnet --version
  3) 重新打开命令行窗口

---

问题 6: 后端编译失败
  错误: "编译错误"
  
  解决方案:
  1) 查看详细错误信息:
     cd RadarSystem.WebAPI
     dotnet build --verbosity normal
  2) 检查代码语法错误
  3) 确认所有 NuGet 包已还原:
     dotnet restore

📝 重要文件位置
--------------
  启动脚本:  启动系统.bat
  备用脚本:  start.ps1
  
  前端源码:  RadarSystem.WebAPI\ClientApp\src\
  前端输出:  RadarSystem.WebAPI\wwwroot\
  前端配置:  RadarSystem.WebAPI\ClientApp\vite.config.ts

  数据库:    RadarSystem.WebAPI\Data\radar.db
  日志文件:  RadarSystem.WebAPI\logs\

🛑 停止系统
--------------
  在运行窗口中按: Ctrl + C

📝 高级选项
--------------
  使用 PowerShell 脚本:
  
  # 标准启动
  > .\start.ps1

  # 跳过前端构建
  > .\start.ps1 -SkipBuild

  # 开发模式（热重载）
  > .\start.ps1 -DevMode

  手动构建前端:
  > cd RadarSystem.WebAPI\ClientApp
  > npm install
  > npm run build
  
  手动启动后端:
  > cd RadarSystem.WebAPI
  > dotnet run

💡 小贴士
--------------
  1. 首次运行需要下载依赖，时间较长
  2. 如已有构建产物，脚本会询问是否重新构建
     - 按 Y 重新构建（代码有更新时）
     - 按 N 跳过构建（快速启动）
     - 10秒不选择自动跳过
  3. 前端构建输出直接到 wwwroot 目录
  4. 系统会自动打开浏览器访问前端
  5. 数据库文件会自动创建和初始化
