# 设备数据接收与保存完整分析报告

## 📋 需求说明

### 核心要求
1. **不需要预先验证设备配置** - 只要接收到完整的设备数据就保存
2. **按设备ID和日期组织存储** - 原始数据按 `{DeviceID}/{Date}/{UUID}` 格式保存
3. **数据完整性校验** - 使用MD5或其他方式验证数据完整性
4. **实时通知** - 数据保存后通过MQTT通知前端
5. **TDengine存储** - 元数据保存到时序数据库

## 🎯 C#实现方案

### 架构设计

```
设备数据接收流程：

1. Netty Handler 接收原始字节
       ↓
2. 解码器解析数据包（RadarDecoder）
       ↓
3. 业务处理器处理数据（RadarServerHandler）
       ↓
4. 数据入队列（异步）
       ↓
5. 后台线程处理队列
       ↓
6. MD5校验 → 保存文件 → 存TDengine → 发送MQTT
```

#### 1. RadarDataReceiver.cs - 数据接收服务

```csharp
/// <summary>
/// 雷达数据接收服务 - 不验证设备配置，直接接收完整数据
/// </summary>
public class RadarDataReceiver
{
    private readonly BlockingCollection<RadarDataPacket> _dataQueue;
    private readonly ILogger<RadarDataReceiver> _logger;
    private readonly Thread _processThread;
    
    public RadarDataReceiver()
    {
        _dataQueue = new BlockingCollection<RadarDataPacket>();
        _processThread = new Thread(ProcessDataQueue);
        _processThread.Start();
    }
    
    /// <summary>
    /// 接收雷达数据（不验证设备是否配置）
    /// </summary>
    public void ReceiveData(byte[] data, string remoteAddress)
    {
        try
        {
            // 解析数据包
            var packet = ParseDataPacket(data);
            
            // 加入队列（不验证设备配置）
            _dataQueue.Add(packet);
            
            _logger.LogDebug("接收到雷达数据: DeviceId={DeviceId}, Length={Length}", 
                packet.DeviceId, data.Length);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "接收雷达数据失败");
        }
    }
}
```

#### 3. RadarDataProcessor.cs - 数据处理服务

```csharp
/// <summary>
/// 雷达数据处理服务 - 后台线程处理队列
/// </summary>
public class RadarDataProcessor
{
    private readonly ITDengineRepository _tdRepository;
    private readonly IRadarFileStorage _fileStorage;
    private readonly IMqttService _mqttService;
    private readonly ILogger<RadarDataProcessor> _logger;
    
    /// <summary>
    /// 处理数据队列（后台线程）
    /// </summary>
    private void ProcessDataQueue()
    {
        while (!_cancellationToken.IsCancellationRequested)
        {
            try
            {
                if (_dataQueue.TryTake(out var packet, 100))
                {
                    ProcessDataPacket(packet);
                }
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "处理数据队列失败");
            }
        }
    }
    
    /// <summary>
    /// 处理单个数据包
    /// </summary>
    private async Task ProcessDataPacket(RadarDataPacket packet)
    {
        try
        {
            // 1. MD5校验
            if (!ValidateMD5(packet))
            {
                _logger.LogWarning("数据MD5校验失败，丢弃: DeviceId={DeviceId}", packet.DeviceId);
                return;
            }
            
            // 2. 生成文件路径（按设备ID和日期）
            string filePath = GenerateFilePath(packet);
            
            // 3. 保存文件
            await _fileStorage.SaveRadarDataAsync(filePath, packet.RawData);
            
            // 4. 保存到TDengine
            await SaveToTDengine(packet, filePath);
            
            // 5. 发送MQTT通知
            await NotifyFrontend(packet, filePath);
            
            _logger.LogInformation("雷达数据处理成功: {FilePath}", filePath);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "处理数据包失败: DeviceId={DeviceId}", packet.DeviceId);
        }
    }
}
```

#### 4. RadarFileStorage.cs - 文件存储服务

```csharp
/// <summary>
/// 雷达数据文件存储服务 - 按设备ID和日期组织
/// </summary>
public class RadarFileStorage : IRadarFileStorage
{
    private readonly string _baseDataPath;
    private readonly ILogger<RadarFileStorage> _logger;
    
    /// <summary>
    /// 生成文件路径：/data/project/{projectId}/radar/{deviceId}/{yyyyMMdd}/{Type}{UUID}
    /// </summary>
    public string GenerateFilePath(RadarDataPacket packet)
    {
        // 数据类型映射
        string dataTypePrefix = packet.DataType switch
        {
            "00" => "X",  // 形变
            "01" => "F",  // 复散射
            "02" => "Z",  // 置信度
            "06" => "M",  // MIMO
            _ => "U"      // 未知
        };
        
        // 按日期创建目录
        string datePath = DateTime.Now.ToString("yyyyMMdd");
        string uuid = Guid.NewGuid().ToString("N");
        
        // 完整路径
        string fullPath = Path.Combine(
            _baseDataPath,
            "project",
            packet.ProjectId ?? "DEFAULT",
            "radar",
            packet.DeviceId ?? packet.SlaveId,  // 优先用DeviceId，没有就用SlaveId
            datePath,
            $"{dataTypePrefix}{uuid}"
        );
        
        return fullPath;
    }
    
    /// <summary>
    /// 保存雷达数据文件
    /// </summary>
    public async Task SaveRadarDataAsync(string filePath, byte[] data)
    {
        try
        {
            // 确保目录存在
            string directory = Path.GetDirectoryName(filePath);
            if (!Directory.Exists(directory))
            {
                Directory.CreateDirectory(directory);
            }
            
            // 写入文件
            await File.WriteAllBytesAsync(filePath, data);
            
            _logger.LogDebug("文件保存成功: {FilePath}, Size={Size}", filePath, data.Length);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "保存文件失败: {FilePath}", filePath);
            throw;
        }
    }
}
```

#### 5. MD5验证服务

```csharp
/// <summary>
/// 数据完整性校验服务
/// </summary>
public class RadarDataValidator
{
    /// <summary>
    /// MD5校验
    /// </summary>
    public static bool ValidateMD5(RadarDataPacket packet)
    {
        try
        {
            // 协议格式：[Header(12)] [MD5(16)] [Data]
            int md5Start = 12 + 4;   // offset + 4
            int md5End = 12 + 20;    // offset + 20
            
            // 提取数据包中的MD5值
            byte[] packetMD5 = new byte[16];
            Array.Copy(packet.RawData, md5Start, packetMD5, 0, 16);
            
            // 计算实际数据的MD5
            byte[] actualData = new byte[packet.RawData.Length - md5End];
            Array.Copy(packet.RawData, md5End, actualData, 0, actualData.Length);
            
            using (var md5 = MD5.Create())
            {
                byte[] computedMD5 = md5.ComputeHash(actualData);
                
                // 比较MD5值
                return packetMD5.SequenceEqual(computedMD5);
            }
        }
        catch (Exception ex)
        {
            return false;
        }
    }
}
```

## 🔄 完整数据流程

### 流程图

```
┌─────────────────┐
│  雷达设备       │
└────────┬────────┘
         │ TCP/Netty
         ↓
┌─────────────────┐
│ RadarDecoder    │ ← 解析数据包
└────────┬────────┘
         │
         ↓
┌─────────────────┐
│RadarDataReceiver│ ← 不验证设备配置
└────────┬────────┘
         │
         ↓
┌─────────────────┐
│  BlockingQueue  │ ← 异步队列
└────────┬────────┘
         │
         ↓
┌─────────────────┐
│后台处理线程      │
└────────┬────────┘
         │
         ├──→ MD5校验
         │
         ├──→ 生成文件路径
         │    (/{projectId}/radar/{deviceId}/{yyyyMMdd}/{Type}{UUID})
         │
         ├──→ 保存文件
         │
         ├──→ 保存到TDengine
         │    (元数据：设备ID、时间、路径等)
         │
         └──→ 发送MQTT通知
              (前端实时更新)
```

### 关键决策点

1. **是否验证设备配置？** → ❌ 否
   - 理由：需求明确"不需要先匹配数据库"
   - 好处：提高接收效率，避免数据丢失

2. **如何组织文件？** → 按设备ID + 日期
   - 格式：`/{projectId}/radar/{deviceId}/{yyyyMMdd}/{Type}{UUID}`
   - 好处：易于查询、管理、备份

3. **何时校验完整性？** → 接收后立即校验
   - 方法：MD5哈希比对
   - 失败：丢弃数据并记录日志

4. **是否同步保存？** → 异步队列处理
   - 理由：避免阻塞网络接收
   - 实现：BlockingCollection + BackgroundService
